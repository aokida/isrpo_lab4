# Математические формулы
## 1. Общее описание функционала
Программы для которых рассчитываются периметр и площадь:
- Окружность
- Квадра
- Прямоугольник
- Треугольник
## 2. Описание каждой функции с примерами вызовов
### Площадь
- Возвращает площадь окружности  $R$, c помощью формулы: $S = \pi R^2$
```
area(3)
28.274333882308138
```
- Возвращает площадь квадрата со стороной $a$, c помощью формулы: $S = a^2$
```
area(3)
9
```
- Возвращает площадь прямоугольника со сторонами $a$ и $b$, c помощью формулы: $S = ab$
```
area(3, 4)
12
```
- Возвращает площадь треугольник со стороной a и высотой h, опущенной на $a$, c помощью формулы: $S = \frac{ah}{2}$
```
area(3, 4)
6
```
### Периметр
- Возвращает длину окружности с радиусом $R$, c помощью формулы: $S = 2\pi R$
```
perimeter(3)
18.84955592153876
```
- Возвращает периметр квадрата со стороной $a$, c помощью формулы: $S = 4a$
```
perimeter(3)
12
```
- Возвращает прямоугольник со сторонами $a$ и $b$, c помощью формулы: $S = 2(a+b)$
```
perimeter(3, 4)
14
```
- Возвращает периметр треугольника со сторонами a, b, c, c помощью формулы: $S = a+b+c$
```
perimeter(2, 3, 4)
9
```
